# Recompilation Projects

A directory of independently maintained recompilation projects for the Ocarina of Time remake. This page is intended to help document ongoing development, identify related projects, and provide links to their original sources.

Inclusion in this directory does not imply affiliation, endorsement, compatibility, or verification of project functionality.

## Adding or Updating Projects

To add a project or update an existing entry, submit a pull request or open an issue.

Please include:

- Project name
- Original project link
- Project type
- Brief description
- Status, if known

Whenever possible, entries should link directly to the project's original source or official project page rather than third-party download mirrors.

## Maintenance

This directory is community-maintained. Project availability, development status, ownership, and links may change over time. Contributions to correct outdated information or add additional projects are welcome.

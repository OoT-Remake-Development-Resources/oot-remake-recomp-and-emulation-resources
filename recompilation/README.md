# Recompilation

This directory contains research, documentation, resources, and development-related materials concerning recompilation of the Ocarina of Time remake.

The purpose of this directory is to provide a shared workspace for investigating recompilation-related approaches, documenting findings, organizing relevant tools, and facilitating collaboration.

## Categories

- **[Research](research/README.md)** – Technical investigations, documented observations, analysis, findings, and other research relating to recompilation.
- **[Tools](tools/README.md)** – Tools, utilities, and software relevant to recompilation research and development.
- **[References](references/README.md)** – External projects, documentation, publications, and other resources relevant to recompilation.

## Research and Documentation

Research documented within this directory should clearly distinguish direct observations, verified findings, assumptions, and hypotheses.

Where applicable, documentation should identify relevant software versions, testing conditions, methodology, evidence, limitations, and verification status.

This directory is intended to evolve alongside ongoing research and development. Additional categories may be established as new needs emerge.
